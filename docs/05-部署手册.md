## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| Java 运行环境 | **JRE/JDK 8 或更高版本**（实测构建与运行：Oracle JDK 21.0.6） |
| 操作系统 | Windows 7 及以上 / 主流 Linux 发行版 / macOS（纯 Java，跨平台） |
| 磁盘空间 | 可执行 jar 约 30 KB；另需 Maven 构建空间（仅从源码构建时） |
| 内存 | 无特殊要求；哈希按 4096 字节分块，内存占用恒定 |
| 网络 | **运行不需要网络**；仅首次 Maven 构建需访问中央仓库下载 JUnit/插件 |

检查 Java 是否已安装，在终端执行：

```
java -version
```

能看到 `version "1.8..."` 或更高版本即满足要求。

## 2. 获取方式

- **方式一（直接使用）**：取得已构建好的 `target/hash-check-tool-1.0.0.jar` 与启动脚本；
- **方式二（从源码构建）**：取得完整工程目录后，在项目根目录执行：

```
mvn clean package
```

构建成功后在 `target/` 目录生成 `hash-check-tool-1.0.0.jar`，其 `META-INF/MANIFEST.MF` 已包含 `Main-Class: com.hashcheck.ui.HashCheckGUI`。

## 3. 启动方式

### 3.1 Windows（推荐：双击启动脚本）

双击项目根目录下的 **`运行-哈希校验工具.bat`**：

- 脚本自动定位同目录 `target/` 下的 jar；
- 优先使用 `javaw` 启动，**不弹出黑色控制台窗口**；
- 若未找到 jar 或 Java，会给出英文提示（图形界面本身为全中文）。

### 3.2 Linux / macOS

在项目根目录执行：

```bash
chmod +x run.sh
./run.sh
```

### 3.3 命令行直接启动（任意平台）

```bash
java -jar target/hash-check-tool-1.0.0.jar
```

Windows 下若希望无控制台窗口，可改用：

```
javaw -jar target\hash-check-tool-1.0.0.jar
```

## 4. 首次使用验证步骤（5 分钟）

1. 双击 `运行-哈希校验工具.bat`，出现标题为“本地文件完整性哈希校验工具 v1.0.0”的窗口；
2. 点击“选择文件...”，任选一个文本文件，路径显示在“已选路径”行；
3. 算法保持 `MD5`，点击“开始校验”，结果区出现 `[1] 路径 | MD5 | 32 位哈希值`，进度条显示 `1/1`；
4. 切换算法为 `SHA-256` 再次校验，得到 64 位哈希；
5. 点击“选择文件夹...”选中一个含若干文件的目录，观察结果逐条追加、进度递增、计算期间可拖动窗口（界面不卡顿）；
6. 点击“导出报告”，选择保存位置，用记事本打开导出的 txt，核对标题、时间、算法、明细与“成功/失败”统计；
7. 点击“清空”，结果区恢复初始表头。

界面布局参见测试报告中的截图：`docs/images/gui-smoke.png`。

## 5. 常见问题（FAQ）

### Q1：双击 jar 没有反应 / 提示“找不到 Java”

系统未安装 Java 或未正确关联。请安装 JRE 8+，安装时勾选“设置 JAVA_HOME/加入 PATH”，或使用启动脚本（脚本会检测并提示）。命令行执行 `java -version` 可验证。

### Q2：导出的报告用旧版记事本打开中文乱码

报告为 **UTF-8** 编码（跨平台统一）。Windows 7 旧版记事本可能以 ANSI 解读导致乱码，请使用 Windows 10/11 记事本、Notepad++、VS Code 等支持 UTF-8 的编辑器打开。

### Q3：个别文件显示“失败：FileNotFoundException …”或 IO 错误

文件在校验期间被移动/删除、被独占占用，或当前用户无读取权限。工具会跳过该文件继续完成其余文件，不影响批量结果；请检查文件权限后对该文件重新校验。

### Q4：选择的文件夹极大、文件极多怎么办

递归扫描深度受调用栈限制（常规目录无影响），计算采用 4 线程并发 + 分块读取，可放心使用；超深目录的迭代式遍历改造见《维护手册》扩展指南。

### Q5：窗口在高分屏下显示不全怎么办

v1.0.0 已对窗口位置做屏幕可用区域夹紧；如仍异常，请将显示器缩放设置为 100%–150% 之间或最大化窗口使用。

## 6. 卸载方式

本工具为绿色软件：删除工程目录（含 jar）即可，不写注册表、不产生系统服务。Maven 构建缓存位于用户目录 `.m2`，与其他 Java 项目共享，一般无需删除。
